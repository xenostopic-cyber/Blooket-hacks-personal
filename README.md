# Blooket Hacks

This repository contains a collection of scripts designed **for hacking blooket**  because apparently some of y’all would rather break the game than study.

## ⚙️ Tampermonkey Installation & Usage

1. Install [Tampermonkey](https://www.tampermonkey.net) for your browser.
2. Open the Tampermonkey dashboard.
3. Create a **new userscript**.
4. Delete the default template code.
5. Paste the contents of `hacks.js`.
6. Save the script (`Ctrl + S` or `Cmd + S`).
7. Open Blooket and the script should load automatically.

> **Note:** These scripts may violate Blooket’s Terms of Service. Use them at your own risk.
